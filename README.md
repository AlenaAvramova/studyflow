# StudyFlow

A  Pomodoro study timer that is customizable, developed during
the SAP Labs Bulgaria Mentorship Program.

## MVP Features
- Custom study duration
- Custom break duration
- Custom number of sessions
- Recommended break duration


## Technologies
- Java 25
- Spring Boot
- Maven
- Spring Web

## Current Progress
- Spring Boot application running
- GET /api/hello returns JSON
